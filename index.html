🔧 Fix: "Failed to load model"

Why this happens:
Your R2 bucket is publicly accessible (URLs work when opened directly), but it's missing CORS headers that allow browsers to load models via JavaScript.

Quick Fix (2 minutes):

  1. Open Cloudflare Dashboard
  2. Navigate: R2 → pub-5c235c28472546da987ee565ee1a586e
  3. Click the Settings tab
  4. Find "CORS Policy" section (scroll down)
  5. Click "Add CORS Policy" or "Edit"
  6. Paste this JSON configuration:
[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["Content-Length", "Content-Type"],
    "MaxAgeSeconds": 3600
  }
]
  1. Click Save
  2. Refresh this page and the models will load! ✨

Alternative: Using Wrangler CLI

Create a file cors.json with the config above, then run:

wrangler r2 bucket cors put pub-5c235c28472546da987ee565ee1a586e \
  --cors-config cors.json

Note: After saving CORS settings, it may take a few seconds to propagate. Refresh this page to test.
