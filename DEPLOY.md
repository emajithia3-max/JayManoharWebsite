# Deploy Your FTC Robot Portfolio

## 🚀 Quick Deploy Options

### Option 1: GitHub Pages (Recommended - FREE)

**Step 1: Merge to Main Branch**
1. Go to: https://github.com/emajithia3-max/JayManoharWebsite
2. Click **"Pull requests"** tab
3. Click **"New pull request"**
4. Base: `main` ← Compare: `claude/ftc-robot-portfolio-3d-011CUiFTigxkUGCG56HPvKHo`
5. Click **"Create pull request"**
6. Click **"Merge pull request"**
7. Click **"Confirm merge"**

**Step 2: Enable GitHub Pages**
1. Go to: https://github.com/emajithia3-max/JayManoharWebsite/settings/pages
2. Under "Branch":
   - Select: **main**
   - Folder: **/ (root)**
3. Click **"Save"**
4. Wait 2-3 minutes
5. Your site will be live at: **https://emajithia3-max.github.io/JayManoharWebsite/**

---

### Option 2: Vercel (FREE - Fastest)

**One-Click Deploy:**
1. Go to: https://vercel.com/new
2. Sign in with GitHub
3. Import: **emajithia3-max/JayManoharWebsite**
4. Framework: **Other**
5. Root Directory: **.**
6. Click **"Deploy"**
7. Live in 30 seconds! 🚀

**Your URL:** `https://jay-manohar-website.vercel.app` (or custom domain)

---

### Option 3: Netlify (FREE - Easy Custom Domains)

**Drag & Drop Deploy:**
1. Go to: https://app.netlify.com/drop
2. Drag `/home/user/JayManoharWebsite/` folder onto page
3. Instantly deployed!

**OR Connect GitHub:**
1. Go to: https://app.netlify.com/start
2. Connect GitHub
3. Select: **JayManoharWebsite** repo
4. Branch: **claude/ftc-robot-portfolio-3d-011CUiFTigxkUGCG56HPvKHo**
5. Click **"Deploy"**

**Your URL:** `https://random-name-123.netlify.app` (rename to `jay-manohar-ftc.netlify.app`)

---

### Option 4: Cloudflare Pages (FREE - Best R2 Integration)

**Connect GitHub:**
1. Go to: https://dash.cloudflare.com/pages
2. Click **"Create a project"**
3. Connect GitHub
4. Select: **JayManoharWebsite**
5. Production branch: **main** (or feature branch)
6. Build settings: **None** (static HTML)
7. Click **"Save and Deploy"**

**Your URL:** `https://jay-manohar-website.pages.dev`

**Benefit:** Same account as your R2 bucket!

---

## 🎯 Recommended Path:

**For Quick Deploy:** Use **Vercel** (30 seconds, auto-updates on git push)

**For GitHub Integration:** Use **GitHub Pages** (free, simple, `.io` domain)

**For Custom Domain:** Use **Netlify** or **Cloudflare Pages**
